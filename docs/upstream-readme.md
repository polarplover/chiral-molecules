十篇依据真实发现过程写成的中文图像推理故事，面向大学一年级学生及对科学与人文探索感兴趣的读者。

## 怎么玩

十篇共384个图文短页、132处推理。原有恐龙与mRNA故事各48页，八篇新故事各36页、12道题。每页只推进一件事；在转折处，根据当时掌握的证据选择一个最佳答案。

答错会出现明显提示和短动画，播放所选选项的解释，再由玩家重新作答；答对后出现确认动画和不同提示音，才可继续。看提示不会直接通关。关键追问会突出显示并收入线索本。396个选项都有普通话合成配音，可随时停止、重播或关闭声音，音频失败不会阻止通关。

## 体验发现的过程

科学发现也有热切的期待、迟迟没有结果的迷惘、合理反对带来的压力，以及线索终于接上时的兴奋。正文、人物姿态、画面距离与光线共同表现这些变化：从具体研究目标出发，让希望接受重复、空白、反例与新比较的考验。情绪来自研究处境和证据进展；原有科学条件、题目和解释保留。

故事模式提供30处由你亲手翻开的记录，让关键图文与读数在打开之后出现；20组不计分的倾向与回望，允许你先留下想法，再看后来的证据怎样改变它。可以暂不选择，也不需要猜中历史才能前进；改变看法或继续求证都不会被计为错题。

20则有出处的经历侧记，补入当事人的回忆、书信以及机构保存的研究经历，并明确材料性质。它们帮助理解人的投入和疑惑，不冒充未被记录的独白、争吵或现场对白。阅读中可切换“故事模式”和“简洁阅读”；简洁阅读直接呈现图文，减少额外停顿与倾向互动，保留同样的科学内容与推理题。

短氛围声默认关闭，可自愿开启，随发现过程的节奏作轻微变化。声音由浏览器在本机合成，不是历史现场录音，也不是科学家人物配音；不取代或改变原有选项解析，答题与播放解析时会停止氛围声。关闭声音或改用简洁阅读都能继续完整游玩。

十关384个短页使用64组六格GPT插画。建议路线前两关“聪明汉斯”与“氩”的72页保留，其余八关的312页按同一标准重新绘制。场景、比较条件、已出现的结果和证据关系直接进入画面，减少在长段文字中寻找信息的负担。游戏与放大窗口只显示当前页，精确条件和读数由可访问的文字标注承担；原有科学图解、研究照片和论文图保留为可展开的对照资料。

图像按阅读进度加载；若插画未能载入，自动显示本页现有科学资料并给出提示，仍可阅读和作答。关键结果在打开记录前保持封存，预判和题页不预先给出尚未知晓的结果。部分六页组会分别选用不同完整原稿中已审核的对应格，浏览器只显示当前页，原始画稿没有拼接或修改像素。

插画和图解不冒充历史照片、原论文图件或实测记录，人物、器材与空间关系可能经过简化。原始史料、研究背景、人物、术语与来源入口可按需展开。教学示例与历史读数分别标明。

## 书签与离线游玩

游玩不需登录，进度和成绩默认只保存在当前浏览器。原有恐龙与mRNA存档键保持不变；旧版书签会迁移。切换故事不会清除进度，重新开始只影响所选故事。同一故事多标签页会合并已有线索，不因回看删除记录。无法保存时会显示提示；线索本支持导出调查笔记。

发现之前的个人倾向与后来的回望也只留在本机，可随调查笔记一并导出；它们不计入成绩，不进入成绩投稿或公开排行榜。已经看过后续证据时，不再补填或改写当时的倾向。

网页版脚本、样式和科学对照资料图集中在index.html中，十关GPT插画按需从comic-art目录加载，解析MP3按需从comic-audio目录加载。需要离线使用时，请[下载完整仓库ZIP](https://github.com/yaoyuzhang1/socrates-question/archive/refs/heads/main.zip)，解压后打开index.html，保持旁边comic-art和comic-audio文件夹的位置不变。不要只下载index.html，否则离线时会缺少新版插画和解析配音。另行提供的本地单文件版已内嵌全部图像和录音。

论文链接、公开排行与投稿需要网络。在线和本地文件、不同浏览器的存档可能相互独立；清除浏览器数据会清除本机进度。

## 成绩、排行榜与评论

每关结束显示百分制成绩、评价、首次独立答对／纠错后答对／借助提示掌握的题数，并列出值得回看的推理。每题等权：首次独立答对计100%题分，纠错后答对计60%，使用提示后答对计30%；最终取各题平均分并四舍五入。阅读速度不计分，听解析与读史料不扣分。

旧存档若能还原全部作答结果，显示可投稿的“旧版参考”成绩；不虚构缺失过程。书架上已通关故事可通过“查看成绩与提交”返回结算页。十关分别排名，同一GitHub账号每关保留仍公开的最高成绩，同分并列。榜单为玩家自报学习记录，不是监考成绩。

玩家自愿填写昵称、星级和评论，预览草稿，再到GitHub登录、核对并确认发布。只有主动发布的内容才进入社区；本机其他书签、笔记和登录凭据不会随成绩上传。公开内容包括账号、所填昵称、成绩及评论。关闭投稿或由管理员标记隐藏后，对应记录会在下一次榜单更新中撤回；若有其他开放投稿，仍会选取其中最高分及最近评论。

榜单从公开Issues自动生成，处理通常需要几十秒至几分钟。打开榜单、从GitHub返回、恢复联网时自动刷新；窗口打开时每20秒检查，并显示更新时间。失败会明确提示，可手动刷新。规则见[社区说明](community/README.md)。
