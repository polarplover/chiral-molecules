## 界面采用的三层标注

- **历史背景/历史观察**：晶体分选、溶解后相反旋光、重混、生物选择性等已记录的研究线索。分选实验对象具体到酒石酸钠铵盐，而不是随便一种“酒石酸晶体”。
- **教学示意/教学对照**：A/B编号、固定朝向八颗晶体、相同浓度/光程/温度/波长/溶剂、正常空白和已知样品、α符号、简化仪器。这些不是 Pasteur 原日志的数值或操作复刻。
- **现代解释**：手性、对映体、外消旋、四面体概念、酶口袋匹配。左右手和二维口袋只是类比，不能替代分子结构测定。

## 必须保留的限制

1. 一个零读数不能独自区分“无效应”与“相反贡献抵消”；灵敏度与测量条件也可能相关。本次证据链针对当前样品。
2. 不能只由镜像晶体外形宣布镜像分子成立。溶解后相反旋光仍存在，是把问题推进到微观层级的重要证据，但仍没有直接给出完整结构。
3. 对映体在非手性环境中的许多物理化学性质相同或十分相近；在相同测量条件下旋光相反，在手性环境中的相互作用可以不同。
4. 小晶面左右标签、(+)/(−)、R/S、D/L不能混用。(+)/(−)记录实验方向，R/S描述绝对构型，两者没有简单对应关系。R/S只放在可选说明。
5. 微生物优先消耗正旋光形式，使剩余液显负方向旋光，支持特定体系中的选择性；不支持“正旋有益、负旋有害”或“所有生命分子都只有一种手性”。
6. 1874年 van ’t Hoff 与 Le Bel 的结构模型属于后续历史，不冒称 Pasteur 1848年已经掌握完整现代三维理论。

本章没有引入具体药物故事，也没有把教学用的 +α/−α 当作历史精确角度。
